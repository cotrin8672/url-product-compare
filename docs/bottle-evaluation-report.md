# 別カテゴリ実商品での検証 — 2026-10-02

充電器の型番違いから離れ、非電気製品の真空断熱水筒を選んだ。公式仕様を確認した2製品で、数値・必須条件とJevの用途評価を別々に検証した。水筒の本番URL対応を追加した実験ではない。

## 対象と事前正解

| 製品                                                                            | 容量  | 保温効力6時間 | 保冷効力6時間 | 開閉・洗浄                                   |
| ------------------------------------------------------------------------------- | ----- | ------------- | ------------- | -------------------------------------------- |
| [THERMOS JNL-S501](https://www.thermos.jp/english/product/detail/jnl-s501.html) | 500ml | 68℃以上       | 10℃以下       | ロック解除後のボタン開閉、全パーツ食洗機対応 |
| [THERMOS JOQ-481](https://www.thermos.jp/product/detail/joq-481.html)           | 480ml | 71℃以上       | 9℃以下        | スクリュー開閉、全パーツ食洗機対応           |

開閉と食洗機対応は [JNL-Sシリーズ](https://www.thermos.jp/product/series/jnl-s01.html)、同ページからリンクする [JNL-S説明書](https://www.thermos.jp/product/series/product_file/file/jnls.pdf)、[JOQシリーズ](https://www.thermos.jp/product/series/joq-01.html) で確認した。食洗機は各説明書・設備の条件に従う。

保温は高い温度、保冷は低い温度を希望条件に照らして評価する。上記はメーカー規定試験の6時間値であり、12時間の保証や利用者の屋外条件へ外挿しない。500mlと480mlを同容量だと丸めない。梱包12個入りを製品の実容量や購入セット数に転用しない。

重量は日本語シリーズ表の0.2kgと英語個別表の約0.21kgなど、表示桁が異なる。概数から205g以内などの厳密な適合を判断せず、その条件は未確認として保留にした。販売店のJAN・価格・在庫・購入単位は今回同定していない。型番・掲載されている色を手で選んだモデルの仕様試験であり、販売店SKUを自動照合した実績には数えない。

[事前正解・仕様・評価軸](bottle-evaluation-cases.json) は実行前に固定した。SHA-256: `259acdb44d748ef84a3c9fe54a4bf05f5ef11632deb65d0baa653cb64ba375af`。結果に合わせて正解や質問を書き換えていない。

## 数値・必須条件の判定

17条件×2実製品で、既存の `rankProducts` に構造化事実を入力した。外部Jevを呼ばないローカルjudgeで、どの商品が採点前に除外・保留されるかを観測した。除外と全体保留を区別するため合致が既知の架空対照を併置したが、対照を実商品数・精度の分母には加えていない。公式の個別ページ2件と機能ページ2件は実取得して確認し、全文は保存・AI送信していない。

| 段階   | 一致    | 誤った適合 | 保留 |
| ------ | ------- | ---------- | ---- |
| 修正前 | 33 / 34 | 0          | 6    |
| 修正後 | 34 / 34 | 0          | 5    |

問題は「保温12時間の値は不明、容量500ml以上が必須」のJOQ-481。容量480mlで不適合が確定しているのに、別項目の欠損を先に検査して全体を保留にしていた。既知の必須条件の不適合を先に除外し、残った候補だけの不足を確認するよう共通処理を修正した。条件の順序を逆にしても結果が変わらず、真に不足している候補を採点しない回帰テストを追加した。

[修正前の原票](bottle-requirements-baseline.json) と [修正後の原票](bottle-requirements-results.json) を保存した。充電器の従来96判定と追加26判定も再実行し、計122判定が事前正解と一致した。

## Jevの実API評価

`jev-1.13.0` に20回実リクエストした。独立した12入力に反復8回を加え、開閉の希望適合と食洗機の希望適合を2軸で採点した。送ったのは自分で作成した短い事実記述とテスト条件であり、公式ページ全文・商品名・ブランド・価格は送っていない。評価用の短い記述の送信は、本番のメーカー情報に包括的なAI利用許諾があるという意味ではない。

既存の評価runnerはカテゴリを充電器に固定していたため、入力ファイルのカテゴリを使用するよう修正した。旧充電器評価は既存の既定値を維持する。

| 指標                              | 結果                                             |
| --------------------------------- | ------------------------------------------------ |
| 応答形式の検証                    | 20 / 20                                          |
| 保留を含めた事前正解との一致      | 35 / 40軸判定 = 87.5%                            |
| 数値ラベルの正解との一致          | 33 / 36軸判定                                    |
| 不明・対象外の4軸で期待どおり保留 | 2 / 4                                            |
| 期待と不一致                      | 5軸：保留1、数値採点違い2、不明・対象外への採点2 |

具体的には、食洗機対応が不明な入力を低評価・確信度0.84で採点した。食洗機を評価しないという条件でも高評価・確信度0.97で加点した。また、希望するボタン開閉への適合を中評価・確信度0.89にした応答があった。高い確信度は正解の保証になっていない。

[実API応答](bottle-jev-results.json) と [同じ応答のオフライン再検証](bottle-jev-replay.json) を保存した。反復は新規商品ではなく、40軸判定は40製品ではない。Jev評価には未知項目を渡した診断も意図的に含む。本番では欠損を事実文字列として渡さず、スキーマと不足確認で止める。評価しない軸は質問自体から除く。今回の結果をもって水筒のJev推薦を公開可能とは判定しない。

## 全体としての判定

数値・必須条件の共通処理は、水筒にも適用でき、追試で見つかった問題を修正できた。しかし現在のWeb/APIは充電器の比較フローであり、水筒のURLは2件ともHTTP 422で未対応となる。カテゴリごとの仕様取得、利用条件フォーム、比較APIの接続は未実装。既知の水筒を手入力した試験が通ることと、任意の水筒URLから比較できることを混同しない。

Jevを全カテゴリにそのまま広げる品質には達していない。数値・確認済み開閉方式・食洗機対象範囲はコードで処理し、意味解釈が必要な軸はカテゴリ別に評価する必要がある。今回の2製品は同一メーカーで、正解作成と確認は同じ担当。第三者評価、市場全体の推薦品質、実機の使いやすさ・漏れ・温度測定は未実施。

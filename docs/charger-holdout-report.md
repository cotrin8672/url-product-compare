## 先に決めた正解

登録前に [26条件と正解](charger-holdout-cases.json) を固定した。SHA-256は `caab664a84aad14440b00f653479423761b8692fa990a19711a22d50c1694cd8`。出力を見てラベルや判定ロジックを変更していない。

| ------------------------------- | -------- | -------------------------------------------- |
| PD 20V・3.25A、5Aケーブル       | 適合     | 固定20Vは3.25Aまで                           |
| PPS 11V・4.05A、5Aケーブル      | 適合     | 低電圧側PPS範囲の上端                        |

## この結果からの判断

この1製品について、PD/PPSを混同せず、電圧範囲と電流の組合せ・端末台数・ケーブル能力を扱えることは確認できた。仕様上の適合判定としては利用可能。一方、未知のURLを入れるだけでどの商品も比較できる状態には達していない。今回は人が確認して1型番を追加しており、自動仕様抽出の精度を実証したものではない。

独立した商品は追加1つ。26条件は相関があり、ラベル作成と実装確認も同じ担当である。市場全体の精度100%とは評価しない。実機の速度・温度・交渉挙動は測定していない。Jevは今回の電気的判定に使用しておらず、この結果をJev精度として扱わない。

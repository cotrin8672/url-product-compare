# 実装状況

更新: 2026-10-13。

全カテゴリを新品限定に統一しました。全商品で未確認の項目と総合評価行は省略し、部分的に確認できる値・0・「なし」は表示します。採点できない数値は仕様として表示し、詳細ボタンには項目数を付けます。順位保留・候補なし・売り切れ時には状況を案内します。

| 機能             | 実装                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| 画面             | 商品URLを送信し、自動カテゴリ判定。曖昧な場合だけ選択。条件・トークン・取消・出典展開の操作なし           |
| 比較表           | 入力商品＋最大5候補。画像と価格（円）、総合・項目別評価（100点）、抽出値、欠損は「—」、共通採点項目を表示 |
| カタログ         | 既存6カテゴリの専用定義と、楽天属性名・Jevによる自動カテゴリ。APIクライアントも定義を検証                 |
| プロバイダ       | URL・ジャンル・取得・補完・成果リンク・利用権限を委譲。実API接続は楽天市場のみ                            |
| 検証・抽出       | 商品状態、URL完全一致、商品同定、引用、期限を検証。商品名・本文の候補からJev Choiceで6商品分を抽出        |
| 採点             | 数値は従来の相対比較。自動属性はJev Scoreで採点し、共通項目の総合を100点換算。欠損や低確信を補完しない    |
| 公開ゲートウェイ | catalog・detect・開始・読取のみ。Bearerはサーバー保持。高コストPOSTをIPごとに1分6回／インスタンス制限     |
| 非同期ジョブ     | 冪等な開始、アクセスキー、所有者・revision・期限による制御。進捗と期限内の結果を復元                      |
| 内部API          | 条件検証、保護された取消、同期互換と既存の充電器・モニター診断を保持                                      |
| 保存             | Firestore作成トリガー、再試行と所有期限、許諾に基づく結果保存、Timestamp TTL                              |
| 公開ページ       | 短い静的HTMLとナビゲーション、本番canonical・sitemap、一時結果のnoindex。Xserver配置対応                  |

受け入れ確認は `rtk mise run verify`。ビルド後のAPI接続確認は `rtk mise exec -- node tooling/verify-comparison-flow.mjs`、公開HTMLの生成と自己検証は `rtk mise exec -- node tooling/build-site.mjs`、配布物確認は `rtk mise run firebase:package` です。通常の検査では外部APIを置換します。2026年10月10日に実商品のコーヒーで値の抽出・100点採点・呼び出し回数・入力トークンを実測しました。結果は[README](../README.md)に記録し、広い商品群の抽出精度・広告成果・収益は未測定です。

2026年10月13日に楽天API・Jevへ実接続し、異なる12カテゴリで入力商品と新品候補を比較しました。宣伝文句と比較例カードを削除し、長い説明は比較条件に格納。主要仕様6項目、短い状態表示、商品名・長い値の展開表示に整理しました。新品の候補検索も改善しました。詳細は[実URLによるUI/UX調査](uiux-real-url-review-20261013.md)に記録しています。

共有キャッシュ、新しい認証基盤、全インスタンス共通の利用者別上限、収益計測、WordPress移行は対象外です。依存追加や検査の緩和はありません。

URLの正規化・商品名による復帰・一回だけの上流再試行・操作キーの競合からの復帰を追加しました。3エージェントでXSS、URL境界、HTTP入力、CSP、応答サイズと期限を確認・修正し、実HTTP10件を検証しています。テレビも新品候補の補充を修正し、実URLで入力商品と別商品の比較が成立しました。詳細は[URL復帰とセキュリティの確認](security-and-recovery-review-20261013.md)に記録しています。

契約は[比較フロー](comparison-flow.md)、方針は[商品仕様](product-specification.md)、追加方法は[カテゴリ・プロバイダ拡張](category-provider-extension.md)、公開HTMLは[Xserver手順](xserver-static-site.md)、起動と基盤設定は[README](../README.md)と[Firebase手順](../infrastructure/README.md)を参照してください。
